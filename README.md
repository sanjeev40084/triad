# triad
A sleek, mobile-first Progressive Web App (PWA) designed to eliminate overwhelm and context switching using a strict **3-task Work-in-Progress (WIP) limit**.

### ✨ Key Features
- **The Rule of 3 Hard Lock:** Capture unlimited tasks in your *Up Next* queue, but only **3 tasks** can live in *Focus Now* at once. New tasks stay locked until you complete an active slot.
- **Work & Personal Contexts:** Filter seamlessly between **All**, **Work** (Coral/Orange), and **Personal** (Mint/Emerald) while maintaining a global 3-slot capacity.
- **Distraction-Free & Title-Only:** Zero bloated sub-fields, due-date anxiety, or clutter—just crisp, scannable task titles and tactile completion animations.
- **Dark Mode & Mobile PWA:** Built with **Plus Jakarta Sans** on deep obsidian surfaces, installable directly onto Android and iOS home screens with offline local storage.

### 📱 Install on Your Phone
1. Open the live GitHub Pages link in **Chrome** (Android) or **Safari** (iOS).
2. Tap **Add to Home Screen** / **Install**.
3. Launch **Triad** full-screen from your app drawer.
